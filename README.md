## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🛡️ Handles division by zero
- 🧩 Clean code: every operation is a separate function

## 🛠️ Tech Used

- **Language:** Python 3
- **Concepts:** Functions, dictionaries, user input, conditionals

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/vishalltomar/python-calculator.git
cd python-calculator
```

**2. Run the program**

```bash
python calculator.py
```

## 💻 Example

```
Enter first number: 10
Enter second number: 5
Choose operation (+, -, *, /): *
Result: 50.0
```
